# Linux Server Administration & Automation

## Overview

This project demonstrates the administration, monitoring, troubleshooting, security inspection, and automation of a Linux server environment.

The environment hosts a simple web application using Nginx and includes practical system administration tasks such as user and group management, file permissions, service management, network inspection, logging, health checks, backups, and incident troubleshooting.

## Problem Statement

A small web application requires a reliable Linux server environment that can be administered securely, monitored for basic health, backed up, and recovered when a service failure occurs.

## Solution

A Linux server environment was configured with Nginx as the web server. User and group access controls were implemented, system and network services were inspected, operational scripts were created, backups were automated, and a simulated Nginx failure was investigated and recovered.

## Objectives

- Manage Linux users and groups
- Configure file ownership and permissions
- Deploy a web server using Nginx
- Inspect network interfaces and listening ports
- Analyze Nginx access and error logs
- Automate system health checks using Bash
- Create automated backups
- Perform basic security inspection
- Troubleshoot and recover from service failures
- Document operational procedures
